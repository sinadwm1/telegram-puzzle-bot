# ربات معمای تلگرام

[English guide](README.md)

ربات تلگرام با مرحله‌های معما، ثبت پیشرفت و جان بازیکن، درخواست راهنمایی و پنل مدیر برای افزودن/ویرایش مرحله و بررسی پاسخ‌ها. داده‌ها در SQLite محلی نگهداری می‌شوند.

## راه‌اندازی

۱. توکن‌های موجود در کدهای اولیه را در BotFather باطل کنید و توکن تازه بسازید.
۲. متغیرهای محیطی `BOT_TOKEN`، `ADMIN_CHAT_ID` و `ADMIN_USERNAME` را تنظیم کنید. فایل `.env.example` فقط نام آن‌ها را نشان می‌دهد؛ برنامه به‌صورت خودکار آن فایل را بارگذاری نمی‌کند.
۳. اجرا کنید:

```bash
pip install -r requirements.txt
python main.py
```

کاربر با `/start` وارد می‌شود و مدیر با `/admin` مرحله‌ها و کاربران را مدیریت می‌کند. فایل پایگاه داده، لاگ و عکس شخصی نسخهٔ اولیه عمداً در این پیش‌نویس نیستند. تست اتصال زنده به تلگرام هنوز انجام نشده و کد با مجوز MIT آماده شده است.
